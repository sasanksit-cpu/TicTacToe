Privacy Policy — Tic Tac Toe Fun!

Effective date: July 11, 2026

The short version: Tic Tac Toe Fun! does not collect or store any personal information on any server. There are no ads, no in-app purchases, and no accounts. Playing against the computer or pass-and-play works fully offline. The optional "Play Online" mode connects two devices directly to each other and shares only the players' chosen nicknames and game moves — nothing is saved anywhere.

1. Who we are

Tic Tac Toe Fun! is a simple tic tac toe game designed for children and families, developed and published by Sasank Sekhar Sahoo. If you have any questions about this policy, contact us at sasank.sit@gmail.com.

2. Information we collect

None. The app does not collect any personal information, usage data, device identifiers, or analytics. It does not require an account, and it does not connect to any server.

3. Online play mode

The optional "Play Online" mode lets two players play together on different devices. When this mode is used:

• A short random room code is created to connect the two devices
• The connection is established with the help of PeerJS, an open-source connection service, which briefly processes device network addresses (IP addresses) solely to connect the two players — a technical necessity for any online game
• Once connected, game moves and the players' chosen nicknames travel directly between the two devices (peer-to-peer)
• No game data, nicknames, or moves are stored on any server
• The connection ends when either player leaves the game

Room codes are random and private — only someone who receives the code or invite link from the player can join their game. We recommend children share room codes only with family and friends they know.

4. The name entered in the app

The app asks players to type a first name so it can greet them during the game (for example, "Your turn, Sam!"). This name:

• Stays on the device, in the app's temporary memory
• Is never saved to any server
• In online mode only, is shown to the other player so the game can say whose turn it is
• Is erased when the app is closed

We recommend children use a first name or a fun nickname only.

Children can also type any nickname or leave it blank — the app works fine without a name.

5. Children's privacy

This app is designed for children and complies with the Children's Online Privacy Protection Act (COPPA), the EU General Data Protection Regulation (GDPR), and Google Play's Families Policy. Because we collect no data at all, no personal information from children is ever gathered, stored, or processed.

6. Advertising and purchases

The app contains no advertising of any kind, no in-app purchases, and no third-party marketing.

7. Third-party services

The app does not use any analytics, advertising networks, social media plugins, or tracking technologies. The only third-party service used is PeerJS (for the optional online mode, described in section 3), which is used solely to connect two players and does not store game data.

8. Permissions

The app does not request access to your camera, microphone, contacts, location, storage, or any other sensitive device permissions.

9. Data security

We store no data on any server, so there is no stored data to secure, lose, or breach. Online game messages travel directly between the two players' devices.

10. Changes to this policy

If we ever update this policy (for example, if a future version of the app adds new features), we will post the new version at this page and update the effective date above. Any future version that changes our data practices will be reflected here before release.
